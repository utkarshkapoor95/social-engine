Two modes, one engine

The same underlying pipeline powers both autonomous posting and human-reviewed content.

Autonomous Mode

Runs daily on a CRON schedule. AI picks a topic from a structured content calendar, generates a caption and image, and publishes to Instagram, LinkedIn, and Pinterest via Buffer. No human input needed. Been running unattended since August 2026.

Human-in-the-Loop Mode

A visitor (or client) submits a topic. AI generates content and sends a preview email with Approve, Revise, or Reject buttons. Only approved content gets published. Built for client-facing use at Posterity Consulting, now repackaged as a live demo below.

AI Content Generation

Groq (open-weight LLM on LPU hardware) writes the caption and hashtags. Cloudflare Flux generates a matching AI image. Cloudinary handles image processing and CDN delivery. All free-tier APIs, zero cost.

Multi-Platform Publishing

Buffer API handles scheduling and posting to Instagram, LinkedIn, and Pinterest from a single workflow. Each platform gets format-optimized content from the same generation step.

Inside the workflow

The actual n8n workflow powering this demo. 15 connected nodes, zero manual steps from topic to published post.

WEBHOOK
Receives the form submission (topic, email, audience, tone) and triggers the pipeline
GROQ LLM
Generates a tailored caption and relevant hashtags using open-weight LLMs on ultra-fast LPU hardware
CLOUDFLARE FLUX
Creates a custom AI image matching the topic, uploaded to Cloudinary CDN for reliable delivery
BREVO EMAIL
Sends the approval email with the full preview, Approve/Revise/Reject buttons, and the AI image
APPROVAL WAIT
Pauses the workflow until the user clicks a button. Revise loops back for a fresh generation
BUFFER PUBLISH
On Approve, posts immediately to Instagram via Buffer API with the caption, hashtags, and image
